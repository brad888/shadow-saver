# 公众号直接转链回复

用户已选定：用户发原始商品链接或淘宝分享内容，公众号直接回原商品的推广链接／淘口令，用户不必进入自有网页。用户选择继续等待免费额度，不购买测试包。

## 实现与验证

- 新增好单库V3 `analyze.clipboard` 客户端，遵循官方SDK签名但使用HTTPS和证书验证。固定 `is_change=1`、`is_unify=0`，传入自有淘宝/京东推广位，不使用官方代结算账号。
- 只采用 `trans_url` 与 `trans_tpwd` 转链字段。校验平台和链接域名，无转链结果时不回传原链接冒充成功，也不搜索替代商品。
- 保留微信安全模式。异步处理总时限3.2秒，重复MsgId缓存回复，按用户限制调用。超时或解析失败返回清楚提示，不等待超过被动回复时限。
- 用户发送关键词时提示发原始链接；内部页面继续作为诊断入口。无需客服主动发送权限，不向用户额外发送测试消息。
- 新功能默认关闭；V3凭据与免费额度未获批前不执行真实收费接口，不更改当前运行配置。
- 用HTTP模拟验证签名、账号归属参数、成功回复、无结果、恶意域名、超时、去重、限流和加密回调。合入远端main后，等待免费额度再真实联调启用。
