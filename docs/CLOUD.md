# Linux 云端与桌面微信连接器

## 部署边界

Linux云端运行现有Docker后端：公众号回调、IM gateway、查询转链、订单账本。Windows或Mac桌面连接器运行在登录微信的用户设备上，通过HTTPS请求后端，不要求云主机安装微信或桌面。

```text
Mac微信 + Mac驱动 ─────┐
Windows微信 + wxauto ──┼── HTTPS ── Linux后端（统一IM/商品接口/订单）
公众号服务器回调 ─────┘
```

此架构不依赖桌面系统；后端不导入AppKit、Swift、wxauto、屏幕识别或桌面权限。现有镜像是Linux镜像，桌面模块只有启动对应连接器时才访问本机系统。微信客户端断线不会阻止公众号工作；云端在线也不代表本机微信在线。

**Linux客户端自动化是另一个问题。** 如果希望个人微信本身也在Linux云端运行，需要受支持的客户端、图形会话、可用的辅助功能/截图接口、持久登录及人工扫码。当前没有Linux微信GUI实机，也没有实现或验证Linux个人微信驱动；不能把普通headless容器视为个人微信机器人。本轮没有购买云资源或部署到未知云账号。

## 迁云前准备

1. 选定常驻Linux主机或持久化容器平台、固定HTTPS域名及预算；当前尚未选择，不自动创建资源。
2. 从远端main已包含的确切提交，在干净检出中构建并测试Linux镜像，上传到用户指定的镜像仓库。镜像架构必须匹配云主机；本机现有运行环境为Linux/arm64，x86_64目标需另构建并验证linux/amd64。以镜像内容摘要发布，记录仓库、SHA、镜像摘要和目标环境，不能只依赖可变tag。
3. 使用持久磁盘保存 `/data/pilot.db` 和 `/data/queries.db`，保持单实例写入；按实际运行UID设置权限。SQLite备份使用online backup并验证完整性，不能运行时只复制主文件。
4. 将私密运行配置从受控文件或密钥管理注入，保持 `DIRECT_LINK_ENABLED=0`，直到免费额度获批并验证。不得把任何密钥烘进镜像或Git。
5. 公网入口只暴露HTTPS；应用8000端口绑定回环或私网。保持关闭完整URL访问日志，避免泄漏登录入口和微信签名。配置 `/readyz` 探针及重启策略。
6. 更新公众号回调域名和服务器IP白名单等适用配置，验证安全模式回调、旧用户身份/订单保留。桌面连接器改为新的HTTPS后端地址；更换域名时先停连接器、重新建立历史基线，不重放历史消息。
7. 为可信桌面设备单独生成绑定 `channel/account_id` 的bridge凭据，勿与其他设备或浏览器共享。备份、撤销、设备丢失流程由管理员负责。

部署操作、数据库备份和恢复见 [OPERATIONS.md](OPERATIONS.md)，IM凭据格式和权限边界见 [IM.md](IM.md)。真正的云部署仍需目标环境、域名和镜像仓库信息，不能凭本地测试宣称已完成。
