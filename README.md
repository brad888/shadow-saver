# 省钱影子 ShadowSaver

个人公众号接入的第一版后端。用户向公众号私聊发送商品文字、商品链接或图片，公众号即时回复本次查询页。当前版本完成消息接收、验签、图片识别、查询页和京东联盟适配器。**京东接口尚未用真实账号联调；淘宝、拼多多尚未接入。**

## 本地运行

需要 Python 3.10 或更新版本。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
cp .env.example .env
```

编辑 `.env`，配置 `WECHAT_TOKEN`、可从微信访问的 HTTPS `PUBLIC_BASE_URL`、公众号的 `WECHAT_APP_ID` 和 43 位 `WECHAT_ENCODING_AES_KEY`。使用公众号消息推送的安全模式时，四项都必须配置，密钥须与微信开发者平台填写的值一致。若要识别图片，还需填 `WECHAT_APP_SECRET`、`DEEPSEEK_API_KEY`。要尝试京东联盟查询，还需填已获批的 `JD_APP_KEY`、`JD_APP_SECRET` 和数字形式的 `JD_SITE_ID`。启动服务：

```bash
set -a
source .env
set +a
.venv/bin/uvicorn shadow_saver.app:create_app --factory --host 0.0.0.0 --port 8000
```

在微信开发者平台「我的业务与服务 → 公众号 → 基础信息 → 消息推送」设置 URL 为 `https://你的域名/wechat`，Token 和 EncodingAESKey 与 `.env` 相同，消息加密选**安全模式**，数据格式选 XML。启用消息推送后，平台原有的自动回复和自定义菜单会失效；请先确认回调服务持续在线。

运行测试：

```bash
.venv/bin/pytest -q
```

## 当前处理流程

1. 验证微信签名，接收公众号的文字、分享链接或图片消息，按 `MsgId` 去重。
2. 立即回复随机生成的结果页地址，避免图片识别超过公众号被动回复的时限。
3. 配置了微信和 DeepSeek 凭据时，后台通过微信素材接口下载图片，调用 `deepseek-flash` 提取商品搜索词。
4. 配置了京东联盟凭据时，用京东商品查询接口获取候选商品，并调用转链接口生成真实推广链接。未取得接口权限、转链失败或未配置凭据时，不展示普通商品网址作为佣金链接。
5. 结果页展示查询状态、京东候选商品、展示价和可用的推广购买入口；最终价格以京东结算页为准。

## 下一步需要的账号权限

现有网站/APP京东适配器使用 `jd.union.open.goods.query` 和 `jd.union.open.promotion.common.get`。已完成真实账号的初步联调，但尚未完成成功查询、转链的验证。淘宝、拼多多各自需要联盟账户、媒体备案／推广位及对应 API 权限；获取权限后再增加适配器。不要把普通商品网址当成自己的推广链接，也不要据展示价推断用户最终结算价。

真实京东接口联调已确认：响应使用 `_responce` 信封以及 `queryResult` / `getResult` 字段，适配器已兼容。个人推客审核、开放平台入驻和创建应用并不代表已取得商品查询权限；接口仍可能返回 `403`。`promotion.common.get` 仅支持网站/APP，公众号媒体 ID 不能作为该接口的 `siteId` 使用。公众号还需确认社交媒体转链接口及推广位权限，在完成对应适配前，不应配置网站专用的 `JD_SITE_ID` 来启用公众号转链。

图片由微信转交给本服务，并在配置识图服务时发送给 DeepSeek。上线前应向用户说明图片处理和推广佣金，设置数据保留期限，并将数据库放在有备份的持久化磁盘上。

## 淘宝官方活动入口（2026-10-27）

公众号精确收到 `红包`、`淘宝红包`、`领红包`、`活动` 或 `淘宝活动` 时，查询运营配置的官方活动并返回结果页。结果页显示平台推广链接；若淘口令生成成功，同时提供可复制的淘口令。普通商品链接不会被当成活动转链。

在 `.env` 配置 `TAOBAO_APP_KEY`、`TAOBAO_APP_SECRET`、`TAOBAO_PID`、`TAOBAO_ACTIVITY_ID`。活动 ID 必须来自淘宝联盟活动中心的官方活动；`TAOBAO_PID` 为推广位 PID。活动 ID 不可使用文档中的示例 `123`。服务启动时需加载环境变量，修改配置后需重启服务。

缺少配置时回复“活动入口暂未开放”；活动过期、尚未开始、时间无法解析或官方未返回可信推广链接时不展示活动。价格、领取资格与优惠金额以官方活动页为准，不展示虚构券额。

验证状态：本地 HTTP 模拟与微信回调测试通过；尚缺运营选定的真实活动会场 ID，未完成真实活动转链联调或公众号上线验证。万能商品转链为高级淘客邀约权限，当前初级账号不可申请；该入口仅调用已获批的官方活动转链接口。

### 固定活动入口

可使用联盟后台为本推广位生成的无线推广链接，配置 `TAOBAO_ACTIVITY_TITLE`、`TAOBAO_ACTIVITY_URL`、`TAOBAO_ACTIVITY_TOKEN` 和 `TAOBAO_ACTIVITY_EXPIRES`。固定入口优先于活动 API，不调用万能商品转链；链接与淘口令由运营人员核对推广位后原样提供。到达停用时间后，新查询与已有结果页均不再展示该入口。停用时间是本服务运营配置，不代表官方活动截止时间，也无法撤回已经复制的链接。
